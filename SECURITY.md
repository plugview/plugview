# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please report it privately through
[GitHub's private vulnerability reporting](https://github.com/MauricioLeon54/plugview/security/advisories/new),
not in a public issue. You will get a reply within 7 days.

plugview reads camera and microphone input locally. It never records, stores, or sends audio or video, and it
makes no network connections.
