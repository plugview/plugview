# Code of conduct

plugview follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion about the work. Harassment of any kind is not
tolerated. Report unacceptable behavior privately to the maintainer through
[GitHub](https://github.com/MauricioLeon54) or by opening a
[private security advisory](https://github.com/plugview/plugview/security/advisories/new) if it needs
confidentiality.
